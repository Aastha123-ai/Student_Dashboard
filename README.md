# Student_Dashboard

Student Performance Dashboard

An interactive Student Performance Dashboard built using Microsoft Excel to analyze student academic performance and attendance. The dashboard provides insights into student count, average marks, attendance, subject-wise performance, class-wise attendance, gender distribution, and pass/fail analysis using KPI cards, charts, and interactive filters. It helps educators monitor student performance and identify key academic trends.

Tools Used

Microsoft Excel
Pivot Tables & Pivot Charts
Slicers
Data Visualization

Key Features

KPI Cards (Total Students, Average Marks, Average Attendance & Total Classes)
Subject-wise Performance Analysis
Class-wise Attendance Tracking
Gender Distribution Analysis
Pass vs Fail Analysis
Interactive Filters (Class & Subject)
